# Target Copy

> **言語：日本語 · [Switch to English →](README.md)**
> [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [Deutsch](README.de.md)

Target Copy は、貼り付け先に合わせて Obsidian のノートや選択範囲をコピーします。
変換はすべて Obsidian 内でローカルに行われます。

## 対応する貼り付け先

Google Docs、Microsoft Word / WPS、Notion、Slack、メール、WeChat 公式アカウント、
ポータブル Markdown、プレーンテキストに対応しています。リッチテキストでは HTML と
プレーンテキストを同時に書き込み、受信アプリが適切な形式を選択できます。

設定で必要な貼り付け先だけを有効にすると、その他の項目は選択画面とコマンドパレットの
両方から消えます。言語はシステム設定に従うか、English、简体中文、繁體中文、日本語、
Deutsch から選択できます。未対応のシステム言語では英語を使用します。

エディターまたはファイルのコンテキストメニューで「貼り付け先を選んでコピー…」に
ポインターを合わせると、有効な貼り付け先がサブメニューに表示されます。選択すると
すぐにコピーされます。リボンとコマンドパレットから選択画面を利用できます。

設定で「元のソース」と「HTML ソース」を有効にできます。元のソースは編集ビューの選択範囲や Markdown/HTML ファイル全体を正確にコピーします。閲覧ビューは Markdown に変換できます。単純な表のリンク・画像・強調を保持し、結合セル、SVG、音声、動画は HTML 構造を保持します。コードブロック内の HTML はコードのままです。Markdown のハイライトはインラインの `<mark>` 要素で保持します。Obsidian リンクには元の Vault へのアクセスが必要です。リンクの対応状況は貼り付け先によって異なり、Google Docs では名前と書式だけが残る場合があります。プレーンテキストには完全なリンク先を含めます。

## コピー操作と詳細設定

選択画面には、選択範囲か文書全体か、入力形式、各貼り付け先のクリップボード形式が表示されます。
貼り付け先の順序は固定され、前回使った項目には印が付きます。

「設定 → Target Copy → 詳細設定」では、有効な貼り付け先の並べ替えと、貼り付け先ごとの
タイトル、内部リンク、ローカル画像の埋め込みを設定できます。各項目は共通設定を引き継ぐこともできます。
埋め込みノートの展開数と階層の上限は、初期値の `0` で無制限です。循環参照や展開できない参照は
出力に残り、コピーの詳細に表示されます。

エディターの選択範囲には、使用する参照リンクと脚注の定義が付属します。元のソースのコピーは選択文字をそのまま保持します。
時間のかかる変換はキャンセルボタンまたはコマンドで停止できます。コピーの詳細コマンドで、直近の成功したコピーに
関する互換性の通知をすべて確認できます。進行状況と互換性の通知は個別に設定できます。

## 手動インストール

1. 配布 ZIP を展開します。
2. 「Vault/.obsidian/plugins/target-copy/」を作成します。
3. main.js、manifest.json、styles.css をそのフォルダーへコピーします。
4. Obsidian を再読み込みし、「設定 → コミュニティプラグイン」で Target Copy を有効にします。

バージョン 1.0.0 は Obsidian デスクトップ向けです。YAML、コメント、
リンク、数式、すべてのコードブロック、SVG/Canvas マークアップ、元の画像データを
保持し、貼り付け先に合わせて外側の形式を整えます。
ウィキリンクは既定でクリック可能な Obsidian リンクに変換され、設定で
`[[ソース構文]]` の保持または表示名のみを選択できます。
