# Target Copy

> **語言：繁體中文 · [Switch to English →](README.md)**
> [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [Deutsch](README.de.md)

Target Copy 會依照「準備貼到哪裡」產生不同的剪貼簿內容。所有轉換均在
Obsidian 本機完成。

想了解它的設計初衷與使用情境，可閱讀
[Target Copy 的產品故事（簡體中文）](https://blog.tanjialin.com/posts/68421)。

## 支援的貼上目標

Google Docs、Microsoft Word / WPS、Notion、Slack、電子郵件、微信公眾號、
可攜式 Markdown，以及純文字。富文字目標會同時提供 HTML 與純文字，讓接收應用程式
選擇合適的表示方式。

在設定中只啟用常用目標後，其他目標會同時從選擇視窗和命令面板消失。介面可跟隨
系統，或指定 English、简体中文、繁體中文、日本語、Deutsch；其他語言使用英語。

在編輯器或檔案的右鍵選單中，將游標停在「選擇複製目標…」即可展開已啟用的目標；
選取目標後會立即複製。工具列與命令面板可開啟完整的目標選擇視窗。

可在設定中啟用「原始碼」與「HTML 原始碼」目標。原始碼逐字複製編輯器選區或整份 Markdown/HTML 檔案；閱讀檢視的內容可轉為 Markdown。簡單表格保留連結、圖片和強調，合併表格、SVG、音訊與影片保留 HTML 結構。程式碼區塊中的 HTML 保持程式碼。可攜式 Markdown 使用行內 `<mark>` 標籤保留文字醒目提示。Obsidian 連結需要存取原 Vault。連結支援取決於目標編輯器；Google Docs 可能只保留名稱和樣式。純文字剪貼簿包含完整的連結位址。

## 複製與進階設定

選擇視窗會顯示選取範圍或全文、來源格式，以及各目標的剪貼簿格式。目標順序保持固定，
並標記上次使用的目標。

在「設定 → Target Copy → 進階設定」中，可以調整已啟用目標的順序，並為每個目標
單獨設定標題、內部連結和本機圖片嵌入；每個選項也可以沿用一般設定。
嵌入筆記的展開數量和巢狀深度預設為 `0`，表示不限。循環或無法展開的引用會保留在輸出中，
並列於複製詳情。

編輯器選取範圍會附上使用到的參照式連結與註腳定義。「原始碼」逐字複製選取文字。
較長的轉換可以透過取消按鈕或命令停止。複製詳情命令會顯示最近一次成功複製的完整相容性提示。
複製進度與相容性通知可以分別設定。

## 手動安裝

1. 解壓縮發行檔。
2. 建立「你的 Vault/.obsidian/plugins/target-copy/」。
3. 將 main.js、manifest.json、styles.css 放入該資料夾。
4. 重新載入 Obsidian，並在「設定 → 第三方外掛」中啟用 Target Copy。

版本 1.0.1 面向 Obsidian 桌面端。外掛保留 YAML、註解、連結、公式、
所有程式碼區塊、SVG/Canvas 標記與原始圖片資料，並依照目標應用程式調整外層格式。
雙向連結預設轉換為可點擊的 Obsidian 連結，也可在設定中保留 `[[原始語法]]`
或只顯示連結名稱。
