# Code of conduct

Target Copy welcomes contributors of every background and experience level.

## Expected behavior

- Be respectful, patient, and constructive.
- Discuss ideas and code rather than attacking people.
- Respect privacy. Never post another person's notes, paths, credentials, or
  identifying information without permission.
- Accept feedback and correct mistakes in good faith.
- Help keep technical discussions focused and accessible.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Sexualized language or imagery.
- Publishing private information.
- Deliberate disruption, spam, or malicious code.
- Retaliation against someone who reports a concern.

## Enforcement

Maintainers may edit or remove contributions and temporarily or permanently
restrict participation when behavior violates this policy. Report sensitive
conduct concerns through the repository's private security reporting channel.
For non-sensitive concerns, contact the maintainers through a GitHub issue.

This policy applies to repository discussions, issues, pull requests, reviews,
and other project spaces.
