# Support

Use GitHub Issues for reproducible bugs and feature requests. Include synthetic
sample content, the Target Copy and Obsidian versions, operating system,
destination application, and steps to reproduce.

Attach a synthetic reproduction with sample names, links, paths, and images.

Use [SECURITY.md](SECURITY.md) for vulnerabilities. General Obsidian questions
belong in the [Obsidian help documentation](https://help.obsidian.md/) or
[community](https://obsidian.md/community).
